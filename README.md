# Cakes by Nashada Jones

Website for Cakes by Nashada Jones: buttercream cakes in London.

A simple site made of plain HTML, CSS and JavaScript (no build step). Open `index.html` to view it.

## Quick edits (all inside `index.html`)
- **Instagram and order form links:** look for `const LINKS` near the bottom.
- **Cake photos:** put the photo in `assets/cakes/`, then add a line to `const CAKES`.
- **Occasion cards:** `const OCCASIONS`.
- **Reviews:** `const REVIEWS`.
- **Prices and FAQs:** search for `price-list` and `faq`.

Brand files (including the burgundy logo versions) are in `assets/brand/`.
